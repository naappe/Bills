# White Saffron Design System

This folder stores the permanent design-system reference for the White Saffron Procurement ERP.

## Files

- `DESIGN_TOKENS.md` — token architecture, colour, typography, spacing, borders, shadows, layout, responsive, accessibility and JavaScript token guidance.
- `LAYOUT_SYSTEM.md` — standard page anatomy and internal section names.
- `COMPONENT_GUIDE.md` — reusable component rules for cards, KPI blocks, forms, tables, buttons and status indicators.
- `PAGE_HELPER.md` — behaviour and maintenance rules for the interactive page helper.

## Source

The design-token reference was supplied as `Pasted text(107).txt`, titled **Complete Tokenization System — Ewity POS Dashboard**. It is a reference system, not an instruction to replace the current White Saffron visual identity.

## Implementation rule

Before changing the interface:

1. Inspect the existing shared tokens and components.
2. Reuse existing White Saffron variables and classes.
3. Adapt useful ideas from this reference only where they improve consistency.
4. Do not replace the application theme, sidebar geometry, typography hierarchy or component depth without explicit approval.
5. Keep changes responsive, accessible and compatible with reduced-motion preferences.
